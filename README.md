# F2026-UTRA-OSOM_Eval

In your local virtual environment, run one of the following:

```pip install -r requirements.txt```

```pip3 install -r requirements.txt```

This will install the packages required for the files

If the ```osom_packages.py``` file is changed to include / exclude a package, run

```pip freeze > requirements.txt```

and replace the current ```requirements.txt``` file.
